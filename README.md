
# 🎮 PONG IN PYTHON

Este es un proyecto personal intentado recrear el famoso juego "Pong" creado por Atari, Inc.

El proyecto fue creado en su mayoria utilizando la libreria de pygame


[Pygame](https://www.pygame.org/)


## 📦 Instalacion

1. Descargar pygame.

```bash
  pip install pygame
```
2. Descargar este repositorio o clonarlo:

```bash
  git clone git@github.com:tomiangeletti/pong-in-python.git
```

## 👾 Jugabilidad / Funciones

Para jugar el jugador debera utilizar ↑ / ↓ para moverse.

A dia de hoy el juego cuenta con:

- Efectos de sonido.
- Menu de inicio.
- Menu de game over.
- Gana el primero en hacer 10 puntos.
